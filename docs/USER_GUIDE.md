# User Guide

Start the program and choose **Load demonstration scenario** to populate a working earthquake-relief network. The main menu then supports:

1. List vehicles, depots and missions.
2. Create a depot and restock it.
3. Register a ground, aerial or amphibious vehicle.
4. Create a mission.
5. Evaluate and dispatch a mission.
6. Save or load the binary snapshot.
7. Print the dispatch audit report.

Dispatch is transactional: validation runs before any stock, fuel, vehicle or mission status is changed. Invalid numeric input is rejected and the menu is shown again.
